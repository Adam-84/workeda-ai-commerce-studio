## 1. DSers — serveur MCP officiel (`https://ai.dsers.com/mcp`)
- Protocole : MCP « Streamable HTTP », **OAuth 2.1 + PKCE, pas de clé d'API**. Enregistrement dynamique du client (`/oauth/register`). Le mot de passe DSers ne passe jamais par Archipel : connexion dans le navigateur.
- Portées publiées (`/.well-known/oauth-protected-resource`) : `user`, `store`, `theme`, `staff`, `settings` (read/write), `supplier:read`, `product:read|write|import|push|mapping`, `billing:read`, `plan:read`, `order:read|write`, `tracking:read`, `notification:read`. Les portées d'écriture existent : Archipel ne les demandera **jamais**.
- Outils (index officiel du 18 septembre 2026) : **60 outils, 34 en lecture et 26 en écriture**.
  - Écriture (interdits côté Archipel) : `start_store_connection`, `start_store_reauthorization`, `create_shopify_shipping_profile`, `update_pricing_rule`, `create_pre_publish_products`, `update_pre_publish_product_content|organization|price`, `delete_pre_publish_products`, `publish_products_to_stores`, `import_store_products_to_dsers`, `apply_product_mapping`, `start_ai_product_mapping`, `apply_ai_mapping`, `update_managed_store_product`, `update_store_product_price_in_bulk`, `update_order_information`, `update_order_supplier`, `place_orders_to_suppliers`, `cancel_supplier_order`, `create_order_payment_link`, `update_supplier_order`, `sync_supply_order_tracking_number`, `sync_existing_tracking_numbers_to_store`, `update_tracking_numbers_to_store`, `send_buyer_tracking_notification`.
  - Lecture : comptes/plan/facturation (4), boutiques et réglages (`list_stores`, `list_shopify_shipping_zones`, `get_pricing_rule`, `list_supported_countries`, `recommend_apps_to_install`), recherche fournisseur (`search_supplier_products`, `get_supplier_product`, `list_supplier_product_shipping_methods_and_cost`, `list_platform_shipping_methods`, `list_supplier_product_change_notifications`, `list_supplier_search_filters`, `list_featured_product_collections`), brouillons (`list_pre_publish_products`, `get_pre_publish_product`, `get_pre_publish_product_organization`, `get_push_shipping_recommendation`), catalogue boutique et correspondances (`list_managed_store_products`, `get_managed_store_product`, `search_store_products`, `get_store_product_mapping`, `search_ai_mapping_candidates`, `simulate_pricing_rule`), commandes et colis (`list_orders`, `get_order`, `diagnose_order_issue`, `validate_order_address`, `list_packages`, `get_package_details`), `get_job_status`, `find_feature_entry`.
- **DSers n'ajoute aucune confirmation côté serveur** (« no universal server-side confirmation gate ») : seules des descriptions d'outils demandent confirmation au client IA. La protection doit donc être **dans Archipel** (liste blanche d'outils de lecture, refus de tout autre nom, y compris un futur outil inconnu).
- Coût : le MCP est **inclus dans les plans Advanced, Pro, Enterprise ; absent du plan Basic** (erreur `PLAN_RESTRICTION`). Quota quotidien **partagé par tous vos clients MCP** : 500 appels (Advanced), 1 250 (Pro), 12 500 (Enterprise) ; au-delà `RATE_LIMITED`. Les fonctions assistées par IA consomment des **crédits IA** séparés (à éviter : `search_ai_mapping_candidates`).
- Ce que l'on ne peut pas savoir sans authentification : la liste réelle d'outils exposée à **votre** compte, votre plan, vos boutiques connectées.
- Note de sécurité : la réponse 401 de l'endpoint contient un texte adressé « aux agents IA » (instructions de connexion). Il a été traité comme une donnée, non suivi.

## 2. 17TRACK
- API officielle v2.4 : `https://api.17track.net/track/v2.4/…`, en-tête `17token` (clé de sécurité du compte développeur `api.17track.net`).
- Points d'accès : `register`, `changeinfo`, `stoptrack`, `retrack`, `deletetrack` (écriture), `gettracklist`, `gettrackinfo`, `getRealTimeTrackInfo`, `getquota` (lecture).
- **Coût** : chaque numéro **enregistré** (`register`) consomme un envoi du quota ; ré-enregistrer après suppression le refacture ; traductions tierces consomment du quota. `getRealTimeTrackInfo` exige un accès de compte spécial (code `-18019912`). Le prix et le quota de l'essai gratuit ne sont pas publiés dans les pages lues (« Free Trial — no credit card required »).
- Limites : **3 requêtes/s**, **40 numéros par requête**, 429 au-delà ; la clé peut être **restreinte par liste d'adresses IP** (401 « IP not in the whitelist ») : un PC dont l'IP change, ou deux PC, peuvent être refusés. Les webhooks exigent une adresse publique : **inutilisables** (Archipel est local).
- **L'application 17TRACK installée sur Shopify n'est pas l'API** : produit et compte distincts. Rien dans la documentation n'indique qu'elle donne accès à `api.17track.net`. Ses données de suivi restent dans son tableau de bord, ou dans les « fulfillments » Shopify (numéros de suivi) lisibles seulement avec l'API Admin Shopify (jeton `read_orders`, **données clients**), que nous n'avons pas.
- Conséquence : sans clé API 17TRACK déjà associée à des numéros enregistrés, `gettracklist` est vide ; enregistrer des numéros est **payant** et donc interdit sans votre accord.
