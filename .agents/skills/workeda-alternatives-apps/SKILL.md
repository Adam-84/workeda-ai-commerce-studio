# Alternatives aux applications Shopify

## Méthode
1. Définis le besoin par la **fonction** à couvrir (pas par le nom de l'application actuelle).
2. Examine d'abord les options **sans nouvelle application** : fonction native de Shopify, réglage ou section du thème, application déjà déclarée qui couvre déjà le besoin.
3. Cherche ensuite des applications candidates **sur sources publiques** (fiche de l'App Store Shopify, site de l'éditeur, page de tarifs). Ouvre la page : ne cite jamais un prix ou une fonction de mémoire.
4. Pour chaque candidate : nom, éditeur, fonction, offre et prix **tels que publiés**, devise, périodicité, date de consultation, lien. Prix ou fonction introuvable = « donnée manquante ».
5. Signale ce qui n'est pas vérifiable : avis de tiers, compatibilité avec le thème de Workeda, performance réelle.

## Comparaison
Tableau : Option | Fonction couverte | Coût publié (source, date) | Effort de migration | Risques (perte de données, de fonctions, de référencement) | Preuve disponible.
Termine par une recommandation prudente : conserver, tester une alternative sur une copie du thème, ou ne rien changer.

## Règles
- Aucune installation, désinstallation ni changement d'abonnement : tu proposes, le propriétaire décide et agit.
- Pas de lien d'affiliation ni de promotion ; un avis commercial d'éditeur n'est pas une preuve d'efficacité.
- Aucune donnée client n'est utilisée ; n'envoie aucune donnée de la boutique à un tiers.
- Une application nouvelle a un coût et un poids de chargement : indique-le, et dis si le bénéfice attendu est démontré ou seulement espéré.
