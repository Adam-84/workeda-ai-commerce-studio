# Déléguer dans l'équipe Workeda

## Étapes
1. **Objectif** : reformule la demande en une phrase et en critère de réussite vérifiable.
2. **Découpe** : une tâche = un livrable = un agent. Si deux tâches se bloquent l'une l'autre, ordonne-les ; sinon elles sont parallèles.
3. **Choix de l'agent** selon le métier :
   - marché, tendances → Sophia ; concurrents, prix relevés → Noah
   - catalogue, fiches, collections → Lucas ; marges, prix → Isabella
   - parcours d'achat, maquettes → Chloe ; code du thème → Ryan
   - contrôle avant validation → Harper ; chiffres de vente, trafic → Benjamin
   - planning, suivi des missions → Olivia
4. **Consigne** : pour chaque agent, écris objectif, contexte utile, données déjà connues (avec source et date), livrable attendu, et ce qu'il ne doit pas faire. Un agent ne voit pas la conversation : tout ce dont il a besoin doit être dans la consigne.
5. **Assemblage** : compare chaque retour à l'objectif, signale les contradictions entre agents, puis fais passer le résultat par Harper avant de le présenter.

## À éviter
- Déléguer sans livrable précis ni critère de réussite.
- Confier à un agent une tâche hors de ses outils (par exemple demander à un agent en lecture seule de modifier un fichier).
- Présenter un livrable non contrôlé comme terminé.
- Toute écriture sur la boutique Shopify : elle reste une proposition soumise à validation humaine.
