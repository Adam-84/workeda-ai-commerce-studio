# Parcours mobile d'abord

## Contrôles
- **Largeur** : la page tient à 360 px sans défilement horizontal ; le texte reste lisible sans zoom (16 px minimum pour le texte courant et les champs de formulaire).
- **Zones tactiles** : au moins 24 × 24 px (WCAG 2.2 niveau AA), visé 44 × 44 px pour les actions principales, avec de l'espace entre deux cibles.
- **Hiérarchie** : sur la fiche produit, l'ordre est photo, titre, prix, variantes, bouton d'achat, puis détails. Le bouton principal reste atteignable au pouce.
- **Formulaires** : un champ par ligne, bon type de clavier (e-mail, téléphone, numérique), saisie semi-automatique activée, erreurs écrites près du champ.
- **Contenu** : accordéons pour les informations longues, pas pour les informations déterminantes (prix, livraison).
- **Performance** : images à la bonne taille, chargement différé sous la ligne de flottaison, pas de décalage de mise en page à l'arrivée des images.

## Livrable
Pour chaque point : constat (écran ou section concernée), problème, correction proposée, priorité. Pour une maquette : description par blocs dans l'ordre de défilement.

## Règles
